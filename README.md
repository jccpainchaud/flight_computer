A flight computer built on an STM32F446RE (ARM Cortex-M4) that reads an ICM-20948 9-axis IMU, a BMP280 barometer, and a BN-220 GPS module. I wrote the IMU and barometer drivers from the datasheets, using DMA and interrupts to keep CPU overhead low. Sensor data is calibrated and fused with a complementary filter, and GPS position and altitude are parsed from NMEA sentences over UART. Prototyped on a breadboard and still in progress.
